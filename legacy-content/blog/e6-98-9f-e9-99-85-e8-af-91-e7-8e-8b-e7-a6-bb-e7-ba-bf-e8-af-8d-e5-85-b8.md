<div id="msgcns!1326AB98D6395CF4!1753" class="bvMsg"> 大量查单词发现在线方式还是不够快，离线词典在天朝的网络环境下还是必不可少的<div>先查了下怎么装，还没来得及亲自试验</div><div>
</div><div><span style="color:rgb(85,85,85);font-family:Verdana, 'BitStream vera Sans', Tahoma, Helvetica, sans-serif;font-size:12px;line-height:17px;">

<span style="font-size:medium;">1、在 </span>[<span style="font-size:medium;">http://stardict.sourceforge.net/cn/Dictionaries_zh_CN.php</span>](http://stardict.sourceforge.net/cn/Dictionaries_zh_CN.php)<span style="font-size:medium;"> 下载所需的词典，注意要选“tarbal”格式的，不要选“RPM”格式的。这里以“朗道英汉字典”为例；
<span></span>
2、下载得到一个“stardict-langdao-ec-gb-2.4.2.tar.bz2”文件；</span>

<span style="font-size:medium;">3、右键单击“stardict-langdao-ec-gb-2.4.2.tar.bz2”文件，选“解压缩到此处”；</span>

<span style="font-size:medium;">4、打开文件夹“文件系统——usr——share”；</span>

<span style="font-size:medium;">5、右键单击文件夹“stardict”，选</span>[<span style="font-size:medium;">“以管理员打开”</span>](http://jandy.cn/blog/?p=1327)<span style="font-size:medium;">；</span>

<span style="font-size:medium;">6、打开文件夹“dic”，如果没有这个文件夹，则新建一个；</span>

<span style="font-size:medium;">7、把文件夹“stardict-langdao-ec-gb-2.4.2”里的3个文件：“langdao-ec-gb.dict.dz、langdao-ec-gb.idx、langdao-ec-gb.ifo”复制到dic文件夹中；</span>

<span style="font-size:medium;">8、重启星际译王，打开菜单——词典管理，即可看到添加的词典。</span>

<span style="font-size:medium;"><span style="color:rgb(0,0,0);font-family:verdana, sans-serif;line-height:21px;"></span></span>

<span style="line-height:28px;font-family:宋体;"><span style="font-size:medium;">现在以安装文件名为</span><span lang="EN-US" style="line-height:28px;"><span style="font-size:medium;">a.tar.bz2 </span></span><span style="font-size:medium;">的词典为例：<span lang="EN-US" style="line-height:28px;"></span></span></span>

<span lang="EN-US" style="line-height:28px;font-family:宋体;"><span style="font-size:medium;">tar -xjvf a.tar.bz2</span></span>

<span lang="EN-US" style="line-height:28px;font-family:宋体;"><span style="font-size:medium;">sudo mv a /usr/share/stardict/dic</span></span>

<span style="line-height:28px;font-family:宋体;"><span style="font-size:medium;">注意：</span><span lang="EN-US" style="line-height:28px;"><span style="font-size:medium;">a.tar.bz2</span></span><span style="font-size:medium;"> 是词典文件，</span><span lang="EN-US" style="line-height:28px;"><span style="font-size:medium;">a </span></span><span style="font-size:medium;">是解压出来的词典目录<span lang="EN-US" style="line-height:28px;"></span></span></span>

<span style="line-height:28px;font-family:宋体;"><span style="font-size:medium;">重新启动</span><span lang="EN-US" style="line-height:28px;"><span style="font-size:medium;">stardict</span></span><span style="font-size:medium;"> ，新的词典就会被自动加载了</span></span>

<font face="宋体"><span style="line-height:28px;"><span style="font-size:medium;">也</span><font color="#000000"><span style="font-size:medium;">可 </span></font></span></font><span style="color:rgb(0,102,0);font-family:Monaco, 'Courier New', monospace;line-height:16px;"><span style="font-size:medium;">sudo cp -a stardict* /usr/share/stardict/dic</span></span>
</span></div></div>
