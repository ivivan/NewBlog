<font size="2" face="微软雅黑">最近看得书也有些，看的电影也有些，看的美剧也有些，无数个零星闲暇的时间对着Blog发呆，连个流水帐都编不出来，一度觉得自己是不是从里面垮掉了~前一阵被问到小说写的怎么样了，基本上现状就是，脑子里有三行，纸上有两行，写到Blog里就剩半行了，而且就这半行还说不上理由的不想动手~</font>

<span style="font-family:微软雅黑;font-size:small;">昨天去看Fire River的烟火，第一次站在人挤人的桥上随着人民群众一起抬头，扭头，转身~烟火没太有什么感觉，颈椎倒是舒服了不少，来澳洲之后好久没有机会仰望星空了~国内那么月朦朦星朦朦，还经常没事抬起头来发发呆，澳洲天高云淡了，反而更多是低头走路了~昨晚做车回家，到家才十一点不到，竟突然都有点打哈欠的冲动了~想想刚来澳洲时每天12点多还在回家的路上游逛，去年那会每天十点多钟还在Mater Hill的车站等车，今年每天五点半刚过就如坐针毡，每天七点钟不到就抱着饭碗朝朝暮暮了~变化总是来源于对比，每天好像都和前一天差不太多，每天却又离过去越来越远~有时候人总是想说我要过这种生活，我要过那种生活，结果却是，生活根本没给你太多的选择~更很多时候，人总是不想因为所遭遇的事情而改变了自己的生活，要和以前一样，要想怎么样就怎么样，结果却是，这种改变也是没得选择~就好比最近看的1Q48，可能就在那么一瞬间，已经不是1984年，而是一个叫1Q84年的全新世界~</span>

<span style="font-family:微软雅黑;font-size:small;">两个周未，解决了村上的1Q84~看书，有点越来越成为一个衡量勇气的指标~看书的冲动总是时不时就来上一下，但是能不能把冲动变成行动就是个鼓起勇气的过程了~挑出一本书，一看页数，先熄灭一部分火苗，一读前几页大概感觉一下内容的体量，又熄灭一部分火苗，手边刷刷微博玩玩手游扫扫网页的诱惑再熄灭一部分火苗，闭起眼睛躺床上发发呆又会勾走部分的心思，最后，如果还能坚持每天看上一部分，那就成功的证明，人性里总还是有自虐的那一部分存在~</span>

<span style="font-family:微软雅黑;font-size:small;">突然想到Two and a half men里的一个片断，Alan和Charles逛书店，Alan情绪崩溃的说这本书也没看过，那本书也没看过，都是名著都没看过人生完蛋了~Charles说你别着急可以现在都买了回去放厕所里每次看一点慢慢来，Alan说不行了，人生剩下的上厕所次数不够了~</span>

<span style="font-family:微软雅黑;font-size:small;">有时候这些搞笑的片断你想想还不完全是纯扯蛋，就我这种没那么丰富感性认知，也不关心流派也不关心年代也不关心风格也不关心趋势，名家只知道最烂俗的，名作只知道最善于宣传的，评论家说往东不走西的盲目看书人士，心里给自己列的书单，影单也是长的不得了~有时候想想，这得什么时候才能看得完啊，在自己还有这份心思和心气之前能看多少呢，以后要是工作了忙碌了为了生存苟活于世了，进度也可能就突然停在这名单的某个位置，然后停个一年，两年，三年，五年，一直到老花镜不离手了，扫扫灰尘，进度颤颤悠悠的继续~</span>

<span style="font-family:微软雅黑;font-size:small;">一般不太会给自己规定下一部要看什么，可看完1Q84后坦白的讲感觉书写的虽然很村上，可所谓向1984致敬的深度明显达不到吧，就特别的想把1984看一遍，又觉得那么色彩浓厚的小说，是不是自己有足够的精力去至少读完它~然后还想看龙应台的大江大海1949，之前回家的时候在饭桌上无意中被推荐，现在总挂在心上是个事儿，看了一页，感觉故事好庞大坚持不住啊~</span>

[![s25996220](http://ivanbuaa.files.wordpress.com/2013/09/s25996220_thumb.jpg "s25996220")](http://ivanbuaa.files.wordpress.com/2013/09/s25996220.jpg)

<span style="font-family:微软雅黑;font-size:small;">一个作家总要至少看两部作品，才显得至少自己留下的印象不会那么偏颇，当然了，如果这个作家能有两部以上力作的话~森村诚一的代表作吧，是真是有点受不太了这种太过于推理为揭露社会问题的风格，最后部分都变成一扫而过了~</span>

<span style="font-family:微软雅黑;font-size:small;">最近眼睛有点太累，看电影的频率被自我限定了一下，也有些因为近期上映的好片太少吧，为了去Myer看场电影最后都得从矮子里拔高个了~</span>

<span style="font-family:微软雅黑;font-size:small;">时隔好久之后从Myer看得又一部电影，看了看上映电影表，看了看IMDB，看了看豆瓣，看了看烂番茄，告诉自己，相信评分，为了别太对不起自己付出的澳币，只能看这个了~然后，唯一的笑点，竟然出现在影片上映之前另一部动画片的宣传剪辑中，一个半小时的电影，唯一的收获就是十一月得去看Freebird~</span>

<span style="font-family:微软雅黑;font-size:small;">新跟了一部美剧，填补一下多年前英雄狗屎后纯科幻美剧的空白~还没太看出什么道道，不过开剧还算不错，英雄尚未出场，美色已经达标了~</span>

<span style="font-family:微软雅黑;font-size:small;">扯了这么多闲蛋，花了我大半个下午的时间，都把逛超市居家过日子的时间段给耽搁了，还没说到我今天突然想写的正题上~</span>

<span style="font-family:微软雅黑;font-size:small;">最近在听网易云音乐的DJ频道，有个摇滚系列做的还算不错，除了每期的榜单重复性太高之外~感觉对于中国摇滚乐，自己从黑豹唐朝Beyond等等起步，听听崔健郑钧何勇高旗等等，虽然限定的圈子小了点不过还一直在国内范畴内，按说慢慢扩展应该挺不错~谁知后来突然Linkin Park横空出世以后爱的不行就彻底的转向欧美音乐了，从此与国内摇滚音乐绝缘多年，对于各种乐队完全处在一无所知的阶段~</span>

<span style="font-family:微软雅黑;font-size:small;">年轻的时候总有这么一种偏颇的认识，反正摇滚的风格都是从欧美传来的，欧美有什么流派国内就会有什么，欧美的大牌乐队又那么多那么正统，那我还听国内的模仿干啥~这种评判的意识也随之扩散到很多生活的方面，很长一段时间之内，感觉有点过于的追随欧美的文化和态度在生活里面~后来反而是人到国外之后，近距离的接触异样的文化，反过头来对于突然消失在自己周围的那种曾经意识不到有什么重要性的中国文化有了强烈的追逐冲动~这个时候再回过头看一看听一听想一想，觉得好些文化上面的东西都不可能是纯粹跨种族跨社会的替代的，总有一些打动你的东西，只能产生在自己的文化当中，虽然在形式上都在国际化，但内容上优秀的本土作品总有一些独特的能打动你的部分~</span>

<span style="font-family:微软雅黑;font-size:small;">反正终归的现状就是，在这么个二十多岁的尾巴上，又重新燃起对于中国本土摇滚圈的热情了，也开始去听听反光镜，痛仰，二手玫瑰等等~</span>
