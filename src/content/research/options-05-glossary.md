## 1. 常用期权策略：本质与最怕什么

| 策略 | 本质 | 最怕什么 |
|---|---|---|
| 买入看涨（Long call） | 用小成本押注上涨，带杠杆的多头 | 长期横盘或慢跌，时间价值把权利金磨光 |
| 深度价内 Call 替代持股（Deep ITM call） | 用深度价内 Call 模拟持股，减少资金占用 | 大跌时亏损接近持股，同时还损失部分时间价值 |
| 备兑开仓（Covered call） | 持有正股并卖出等量 Call，收权利金、降低成本 | 大涨时上行被“封顶”，少赚很多 |
| 卖出看跌（Short put） | 承诺在某价格买入股票，换取权利金 | 快速暴跌被迫高位接货；最大亏损为行权价减权利金，有限但很大 |
| 轮动策略（Wheel） | 先卖 Put 接到股票，再卖 Covered call，循环 | 系统性下跌中一路接盘，仓位失控 |
| 牛市看涨价差（Bull call spread） | 买低行权价 Call、卖高行权价 Call，同一到期 | 只涨一点或横盘，净权利金被时间磨掉 |
| 熊市看跌价差（Bear put spread） | 买高行权价 Put、卖低行权价 Put，同一到期 | 不跌反涨 |
| 买入跨式 / 宽跨式（Long straddle / strangle） | 同时买 Call 和 Put，押注大波动，方向不定 | 实际波动小、IV 回落，两边一起被时间和 Vega 消耗 |
| 卖出跨式 / 宽跨式（Short straddle / strangle） | 同时卖 Call 和 Put，押注价格留在区间 | 单边大行情；裸卖 Call 一侧亏损理论上无限 |
| 铁鹰（Iron condor） | 卖一个 Call 价差加一个 Put 价差，最大亏损固定 | 价格突破任一侧，该侧接近最大亏损 |
| 日历 / 对角价差（Calendar / diagonal） | 组合不同到期（甚至不同行权价）的期权，赚时间价值差 | 快速单边行情，Delta、Gamma、Vega 一起反向 |

## 2. 希腊字母

| 术语 | 含义 | 直观理解 |
|---|---|---|
| Delta | 期权价格对标的价格的敏感度 | Delta 0.5 的一张 Call 约等于持有 50 股；组合的总 Delta 就是等效持股 |
| Gamma | Delta 对标的价格的敏感度 | Gamma 高时，股价小幅波动就会让等效持股剧烈变化，卖方容易被“挤” |
| Gamma 挤压（Gamma squeeze） | 做市商对冲引发的正反馈 | 股价上涨，做市商买入股票对冲，股价进一步上涨 |
| Theta | 每天因时间流逝损失的价值 | 买方每天“付租金”，卖方每天“收租金” |
| Vega | 对隐含波动率的敏感度 | IV 上升，买方受益、卖方受伤；IV 回落时相反 |
| Rho | 对利率的敏感度 | 对一年以上的长期期权影响较大 |

口诀：买入期权是正 Gamma、正 Vega、负 Theta；卖出期权是负 Gamma、负 Vega、正 Theta。

## 3. 波动率与波动结构

| 术语 | 英文 | 含义 |
|---|---|---|
| 隐含波动率 | Implied volatility (IV) | 从期权价格反推出的、市场对未来波动的预期；越高说明市场越紧张 |
| 历史波动率 | Historical volatility (HV) | 根据标的过去一段时间的实际价格波动计算 |
| IV Rank | IV rank | 当前 IV 在过去一段时间（如一年）最高点与最低点之间的位置，0–100 |
| IV 百分位 | IV percentile | 过去一段时间里，IV 低于当前值的时间占比 |
| 波动率微笑 / 偏斜 | Volatility smile / skew | 不同行权价的 IV 不同，反映市场对上行、下行尾部风险的不同担忧 |
| IV 塌陷 | IV crush | 财报等重大事件后，IV 从高位快速回落 |

## 4. 风格与板块

| 术语 | 英文 | 含义 |
|---|---|---|
| 高贝塔成长股 | High-beta growth stock | 对指数涨跌反应放大的高成长公司，指数涨跌 1%，它可能涨跌 2–3% |
| 价值股 | Value stock | 估值较低、现金流稳定，更依赖分红和慢涨 |
| 防御性板块 | Defensive sector | 经济下行时盈利相对稳定，如公用事业、医疗、必选消费 |
| 主题投资 | Thematic / sector play | 围绕某一主题（如 AI、航天、核能）集中的股票或板块 |
| 动量行情 | Momentum rally | 涨的继续涨、跌的继续跌的趋势行情 |
| 避险情绪 | Risk-off / flight to safety | 资金从高风险资产流向现金、国债、黄金等安全资产 |

## 5. 宏观与政策

| 术语 | 英文 | 含义与影响 |
|---|---|---|
| 加息 / 降息 | Rate hike / rate cut | 央行调整基准利率；加息压制通胀但压低估值，尤其对成长股不利 |
| 缩表 | Quantitative tightening (QT) | 央行缩减资产负债表、回收流动性，对风险资产普遍不利 |
| 量化宽松 | Quantitative easing (QE) | 央行买债注入流动性，通常推高风险资产 |
| 利率久高不下 | Higher for longer | 利率长期维持高位，未来现金流折现更多，成长股估值承压 |
| 通胀粘性 | Sticky inflation | 通胀迟迟不降，约束降息节奏 |
| 经济衰退 | Recession | 经济活动连续明显下滑 |
| 软着陆 | Soft landing | 通胀回落、经济放缓但不衰退 |
| 地缘风险 | Geopolitical risk | 战争、制裁、地区冲突对经济和市场的冲击 |
| 风险偏好 | Risk appetite / risk-on, risk-off | 投资者愿意承担风险的程度；高时追逐成长股，低时偏向防守 |

## 6. 交易执行与仓位管理

| 术语 | 英文 | 含义 |
|---|---|---|
| 方向敞口 | Long / short delta exposure | 整体仓位对标的上涨或下跌的敏感方向 |
| 净多头 / 净空头 | Net long / net short | 多空加总后整体偏多还是偏空 |
| 裸卖期权 | Naked option selling | 没有对应正股或现金担保的卖出，风险显著更大 |
| 平仓 | Close position | 了结已有头寸，锁定盈亏 |
| 滚动 | Roll | 平掉当前合约，同时在其他到期日或行权价开新合约 |
| 加仓 / 减仓 | Add / trim | 增加或减少某个标的、策略的仓位 |
| 对冲 | Hedge | 开立相反方向的头寸，降低单一风险 |
| 再平衡 | Rebalancing | 定期调整各资产权重，使其符合风险目标 |
| 滑点 | Slippage | 实际成交价与预期价之差，高波动、低流动性时更大 |
| 流动性 | Liquidity | 是否容易成交、买卖价差是否小 |
| 尾部风险 | Tail risk | 概率很小但损失巨大的事件 |
| 回撤 | Drawdown | 从高点到之后低点的跌幅 |
| 仓位管理 | Position sizing | 给每个标的、策略分配多少资金和风险 |
| 杠杆 | Leverage | 用借款或衍生品放大敞口 |
| 保证金压力 | Margin pressure | 保证金占用接近上限，被迫平仓或无法调整 |
