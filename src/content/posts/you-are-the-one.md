<span style="font-family:微软雅黑;">日照归来就一直很想记录些什么，哪怕有些事情永远不会遗忘。</span><span style="font-family:微软雅黑;">从2.21到4.4，从初识到喜欢，从喜欢到陷入，从陷入到一起，一段复杂的时期，一期短暂的相处，一份纯粹的感情，顺其自然的拥有下去，于我就是最大的幸福．．．</span>

<span style="font-family:微软雅黑;">在这个特殊的时期，出行的快乐，对我来说很大程度上来自与Ａｎｎａ的近距离的相处，在迷人的海边散步与在狭小的大巴上坐聊，都是同样的让我迷恋，只因为我所喜欢的人都在我的身边。从来，没有像今天一样如此的珍惜共同的时间，一种无形的紧迫感，让我不自觉得想把一切可以利用的时间都花在直接的感情的培养上，只是想可以让两个人的心再近一点，再近一点，近到我可以放心的远去．．．</span>

<span style="font-family:微软雅黑;">说是让自己放心，但我从来没有怀疑过彼此坚持的态度，无论是开始，还是现在。从我自己的方面，在北京之行之前，我已经抹去了最后的一丝不确定，全心全意的告别过去，我才可以彻底的投入到现在，我想在这一方面我可以十足的说我做到了，并没有留下所谓的回头路给自己当做分心的借口。另外的坦白的讲，我并不认为我在单身的状态的时候是一个可以一直专一下去的人，单身的我缺少一种约束，而且我也向来不好拒绝，有时候我会有些害怕这种情况发生，所以内心里十分的想能够改变这种身份，因为表白，对于我不只是确立了关系，更有一种责任和约定在里面，很多时候那是一种强大的精神力量可以让我即使在一个人的时候也不会感到孤独。我想在牵手之前，这是我唯一的小小的对自己的不放心。从Ａｎｎａ的角度，就更简单了，怀疑喜欢的人，本身就是个相悖的事情。我想一个值得我喜欢的女生，自然会有自己的判断在里面。</span>

<span style="font-family:微软雅黑;">住在一个房间里让我很是有一种亲切的感觉，喜欢一切能够拉近距离感的方式。虽然也知道毕竟还是有些顾虑在里面，也会欣然的接受如北京之行一般的安排，但还是很高兴能够得到这么大程度上的信任。有时候想想现在的自己，我觉得我是完完全全的想把这段感情发展下去，容不得其它任何的东西在里面打破了这气氛，也算是成熟了一点吧。</span>

<span style="font-family:微软雅黑;">我想在这么个环境中，又当自己明白的知道下一个太阳升起的时候就要告别这短暂而又难得的两人空间，感觉有好多好多的话要对你说，却不知怎么开口。那时，甚至包括现在，我都感觉，因为我们各自的经历和成熟，我们的感情发展少了很多弯路，一直走在最合适的方向上，可也是因为那些原因，我们在这段感情上加上了太多的冷静和思考。虽然我们每个人都经过了很多，都懂得什么样的爱情才是我们想要的，才是可以长久持续的，可把这多年的积累和收获一开始就用在这段才开始一个多月的感情上，得确是有点点太心急了一点，这让我在很多时候有一种感觉，很多答案是确定的，但现在就是无法证实。因为如此，我想我在很多时候还是犹豫了。犹豫一个现在拿不出答案的爱情，你可不可以接受．．．</span>

<span style="font-family:微软雅黑;">在那黑暗中，我看不到你的身影，却清楚的感受到了你的心。而当听到你忧伤的声音的那一刻，我知道不能再去顾虑些什么，错过了，就是一辈子的无法原谅.....我并不是一个悲观的人，可这些天来总有一种感觉，如此般的女生，没有把握住的话不可能再碰到了．．．我不是一个浪漫的人，也不会蜜语甜言，也不够大胆主动，只习惯默默的把你放在我的心里，随你快乐或悲伤，不想去试探什么，只想等待那时刻，那个可以让我完全的放开自己的心的刹那，把你永远的接纳．．．</span>

<span style="font-family:微软雅黑;">那指间的温柔，现在还是那么清晰，抱着Ａｎｎａ的时候，我觉得两个人的心是那么的近，强烈的归宿感，真是好想永远这样下去．．．一开始就有如此的感受，确实连我都没有想到，当卸下外在的种种约束，我才发现两个人的感情是如此的深。我想我们现在的关系也正是如此，内心的感觉上已经靠的很近，可外在的熟悉上却刚刚上路，所以黑暗中我可以那么的放开我的心，可当正视对方时，却又不自然的会去羞涩．．．不要去怀疑这爱的程度，我只是太过爱你．．．</span>

<span style="font-family:微软雅黑;">数次的，与Ａｎｎａ贴的很近，可以清楚的感受到她的气息和温度，很是沉迷于这种感受当中觉得好温馨，很想去吻她，却克制了下来。一来觉得这个环境有点点小爱昧，二来也不想让她觉得太快，三来不想让自己在分别后一个人时更想她。现在发现自己想法真是复杂，而且是当时想出来，还不是现在想出来，逻辑的过头了．．．</span>

<span style="font-family:微软雅黑;">断断续续的回忆了些其中的片断，也算是对单身生活的最后总结和对恢复恋爱身份的肯定，</span><span style="font-family:微软雅黑;">本来么，日照之行写到这里也就差不多了，不过因为最近拖拖拉拉，现在才动笔，那就顺便把这几天的感受也混搭进来．．．</span>

<span style="font-family:微软雅黑;">短暂的轻闲之后随之而来的就是疲惫和忙碌，连续几天都没有机会见面，在ＱＱ上也是等待的时间远多于聊天的时间。结果就是看电影看书写ｂｌｏｇ等等都没什么情绪，昨天好不容易有点时间和Ａｎｎａ聊天，还把我吓到了，或者是日照之行和之后的生活反差太大了吧，她说了好多有关梦和不真实，不确定和犹豫情绪的话，没想到她会有这么强烈的这方面感觉，还是自己做的不够好吧，回来几天都没有主动的要去创造相见的条件，而仅仅是满足在了周未的计划上，我想我应该更加的时刻提醒自己，不能再用对待平常恋情一样对待现在这份感情，这里缺少的本就是时间和见面的机会，千万千万不要现在这根本不值一提的距离而真的给两人增加了距离感．．．</span>

<span style="font-family:微软雅黑;">今天下午安排了下办事顺序，赶在了Ａｎｎａ下课前去陪她，也算是让自己放心放心。一起坐车，一起吃饭，送到路口，还因没牵手意识被鄙视。见面总是很开心，不过我也发现她果然如ＱＱ印象上说，神经很大条，至于为什么这么说，此处不表．．．我懂就行了</span>

<span style="font-family:微软雅黑;">困了困了睡觉，明天北京又是幸福的夜晚～～</span>
